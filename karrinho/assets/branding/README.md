# Karrinho icon

`karrinho-icon.png` is a high-resolution reconstruction of the small shopping-bag
image attached by the user, produced with the built-in image generation tool.
It is not the original attachment file. Expo uses it for the Android launcher
icon and web favicon, generating platform-specific sizes during the build.

Final image-edit prompt:

> Precise-object-edit. Correct ONLY the color fills of this app icon. KEEP all existing geometry, centered shopping bag outline, rounded tile, spacing and proportions unchanged. REMOVE ALL shading, texture, glow, shadows, mottling, transparency and gradients. The entire outside background must be perfectly solid opaque #121814. The rounded square tile must be perfectly solid opaque #283F30. The shopping bag outline must be perfectly solid #A5CEAE with crisp smooth antialiased edges. Exactly three flat solid colors. No text, no new elements. Output one square opaque PNG app icon, 1024x1024.

The tool returned a 1254 × 1254 PNG; the asset is kept at that native resolution.
